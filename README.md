# New Radical

New Radical is a daily sports decision game for young athletes. Players watch one pressure moment from their sport, make the call before the coach reveals the read, build a long-term Decision DNA profile, compete with friends, and progress through themed seasons.

This repository begins with the approved conversion-focused landing page and its visual assets. It is intended to become the working MVP for the full product.

## Start here

1. Read `CLAUDE.md`.
2. Read `PRODUCT-BRIEF.md`.

4. Review `references/` for the internal app direction.

## Product principle

The MVP should feel like a sports game, not an education portal and not a generic social network. The core experience is one compelling daily decision, followed by an immediate coach reveal, meaningful personal progression, squad competition, and season rewards.
